# 管理员暂停管理

管理员登录后，从右上角账号菜单进入“暂停管理”（`#/admin/pauses`）。列表显示自己负责学员的当前暂停和跳过模块，包括尚未补学的已解锁模块，并显示学员、课程、Topic、模块、原因和时间。可以刷新或分页加载。

管理员与学员的归属沿用答疑配置：未单独分配的学员归默认管理员，单独分配立即覆盖默认归属。后端同时过滤列表、总数、分页和解除操作；其他管理员、普通账号、游客都不能越权解除。禁用账号的暂停不在此界面处理，其他管理功能继续由服务器 CLI 提供。

点击“解除暂停”并确认后，按原服务端解锁规则恢复 Topic。当前未完成模块会重新开始，已完成模块、Practice 队列和既有复习记录保留。原子训练按其已有规则接续。列表刷新后移除已处理记录；学员刷新学习页即可继续。旧版 Topic 暂停只显示，不自动迁移或覆盖学习进度，需维护者另行处理。

跳过模块使用“解锁补学”，同一 Topic 的已解锁模块合并为一个 Lesson，未解锁模块继续等待；其他模块复习照常。默认不满足下游前置，可勾选“允许推送下游 Topic”；该勾选只放行跳过条件，正常到期复习、其他暂停及前置条件仍须满足。

公开路由为 `GET /api/admin/pauses`、`POST /api/admin/pauses/unlock` 和 `POST /api/admin/pauses/skip-policy`。解除请求必须指定学习者、Topic、模块（复习单独暂停可为 null）和精确事件；放行请求绑定当前全部跳过事件。所有请求继续受管理员归属、版本、身份、来源、JSON 和体积边界约束。重复提交不会重复新建轮次，旧事件不能解除后来的暂停。接口不返回题目答案、凭据或完整学员学习状态。
