# 问答题转换与私有题库

共享题型用 `interaction.type=choice` 表示单项选择，支持 2–12 项。本次数学「数字化为字母」采用六选一、每道原题一套：第 4 模块的 Example 与全部 Practice 转填空，其余模块转选择。原始 Topic、题目 ID、标准答案、解析、Practice 队列和 FSRS 身份不变。

## 数据与流程

所有原题、API 请求/响应、错误推导和生成题库留在 D 盘产物目录或服务器私密数据目录，不提交源码仓库或 Pages。公开前端只拿已呈现题目的选项，不拿答案键。

1. 从正式服务器只读取得当前 Topic JSON，以课程版本和题目完整内容哈希绑定输入。转换器目前仅接受没有图片依赖的数值型综合范式 Topic；不支持的内容明确拒绝，不静默降级。
2. 第 4 模块机械保留题干并追加一个结果空。沿用语义判题以保留原来“数学上等值的精确表达式”规则，不把原本可接受的表达式收窄为数字字符串。
3. 选择题由配置好的 DeepSeek API 生成错误候选池，每项包含精确数值、错误机制、来源解释和可计算的错误算式。仅使用 Codex 专用密钥，不使用网站判题密钥或配额。
4. 脚本用有理数精确运算排除与正确值等价、彼此等价、算式与数值不符及量级明显不合适的候选。通用表达式识别器还检查题面显然范围：多个介于 0 和 1 的因子相乘，结果必须小于每个因子；整个式子为算术平方根时，结果不能为负。字符相似度只辅助组选，不作为否决规则，也不要求至少三类错误机制。**只改分母、符号或系数可以；两个或多个同样合理的中心可以；要防止的是正确项凸显为唯一中心。** 纯数值变形须如实说明为干扰设计，不能虚构为已观察到的学生错误。
5. 独立语义审核检查各项错因及整组选项。有明确问题的候选从池中剔除，再次组选、重新独立审核，不修改候选的数值或解释。另一份盲审只收到打乱的六个数值，不含题干或正确答案，检查是否有能指向正确项的明显出题模式；盲审只猜到干扰项不作为答案泄露的证据。任何未通过的题目都不会进入可发布题库。
6. 保留每次原始请求、响应、被拒原因和接收结果。缓存绑定来源、模型和工作流版本；恢复时重新校验。修改提示或校验器后从原始输入重跑，禁止直接人工修补候选答案冒充自动流程通过。
7. 使用现有导入器的安全 Markdown/MathJax 编译，再独立回读检查覆盖数量、六项互异、唯一正确值与原答案等价、填空答案和题干未被改写。小样标记 `pilot`，安装器拒绝安装小样。

字符相似度只是辅助筛选，语义审核也可能误判。这里验证的是题库生成、筛选和使用流程；干扰项实际区分度仍需要以后用学生作答数据校准，不将 LLM 审核结果称为实证效果。

## 使用

先运行小样（每模块一题），查看产物和拒绝证据，通过后去掉 `--pilot`。同一个输出目录可续跑，已接收且校验通过的同版本题目不再调用 API。

```powershell
& D:/AppData/GraspMemoEdu/venv/Scripts/python.exe -m graspmemoedu.question_conversion `
  --course '<D盘当前原题JSON>' --output '<D盘私密产物目录>' --blank-modules 4 --pilot

& D:/AppData/GraspMemoEdu/venv/Scripts/python.exe -m graspmemoedu.question_conversion `
  --course '<D盘当前原题JSON>' --output '<同一产物目录>' --blank-modules 4

& D:/AppData/GraspMemoEdu/venv/Scripts/python.exe -m graspmemoedu.question_conversion `
  --course '<D盘当前原题JSON>' --output '<同一产物目录>' --blank-modules 4 --verify-only
```

默认最多三个并发生产请求、每题四次生成尝试；可用 `--workers` 调整为 1–32 个并发，用 `--attempts` 调整为 1–12 次。短暂传输故障最多重试三次，完全相同的请求优先读取原始响应。失败保留证据并使整个正式批次不产生题库；不能只用成功部分宣称完成。

## 发布、历史与恢复

先备份正式站点，再经 SSH 将已验收的私有 `bank.json` 交给 `python -m graspmemoedu.question_bank --course <正式TopicJSON> --bank <题库JSON> --data-dir /var/lib/graspmemoedu`。无网页安装或改题接口。

题库保存在 `question-banks/<topic_id>/<sha256>.json`，`active.json` 原子切换当前版本。已存版本不覆盖、不删除。原课程 JSON 及其 version 不修改，也不为转换重置或迁移学习记录。

每个新 Lesson 步骤固定题库版本；每个新 Review 轮次固定版本。历史步骤/轮次没有该字段时永远读取原题，即使后来安装了题库。新题型的失败重试、历史回答和文字纠错均使用当时固定的版本。缺失或哈希不匹配的版本报错，不偷偷回退到另一道题。只切换 active 指针可以影响后续呈现，不能改写已呈现题目。

格式 2 的整站备份包含所有题库历史文件及当前指针。备份和恢复验证路径、源题哈希、文件内容哈希及数据库引用，旧版没有题库的备份仍可恢复。验证使用 `tests/test_question_bank.py`、备份测试及 `question_bank_fixture.py` / `question_bank_acceptance.mjs` 的隔离真实 Chrome 流程；测试内容不能发布正式课程。
