# 管理员查看学员学习情况

管理员从右上角账号菜单进入“学员学习情况”（`#/admin/students`）。可按姓名搜索、分页查看全站所有学员，点击学员进入详情并手动刷新。普通账号、非学员账号和游客无法访问。

学员从头像菜单进入“个人学习情况”（`#/progress`），复用同一份详情投影和五个分页。`/api/student-report` 及其 `/questions`、`/history` 只从登录身份确定本人，不接受目标学员 ID；管理员接口仍仅管理员可访问。原子训练未掌握卡片的正文、答案和解析沿用原查看限制，材料入口沿用学员正常学习权限。

管理员看到的是邀请码清单对应的私密备注名 `admin_name`；学员看到并可修改的是独立的 `display_name`。备注名不进入登录身份、个人设置、个人报告或学员答疑记录。管理员的学员搜索、详情、答疑与暂停界面均使用备注名。

本页面的“所有学员”指账号标记为 `is_student=1` 且 `is_admin=0`，包括停用账号及标记为测试用途的学员，界面标明相应状态。任何管理员都可查看全站学员；原答疑和解除暂停功能仍只允许管理归属自己的学员。

详情分为概览、全部 Topic、题库、错题本和全部复习排程；保留原有学习明细：

- 概览：当前内容的完成数、题库已做题数、错题本数量、到期任务；最近 7/30/90/365 天的有效作答天数、作答量、系统判题正确率趋势、作答热图与已记录用时。日历按所选月份展开已有复习排程，点击日期查看条目及受阻原因。
- 全部 Topic：按学科、课程及原目录层级展示，包括尚未开始和当前无权限的 Topic。范式进度按完成模块、原子进度按掌握记忆点、纯引论按已读指导段落计算；跳过不算完成，旧版记录不冒充当前版本进度。可筛选学科、状态及名称，展开所有例题、备用 Practice 或原子卡。
- 题库：沿用题库与题组层级，显示已有效作答的不同题目数、题量、正确率和到期数；“已做”不等于掌握。题目按需分页读取，可搜索和筛选。
- 错题本：按既有 `training_memory` 记录展示，包括手动加入未作答的条目，并保留已停止推送的历史项；不另建错题数据库、不改变收录与排期规则。可筛选曾答错、已到期、未作答和停止推送。
- 题目和反复出错知识点均可展开已完成作答历史：题目、该学员提交的答案、判题结果、原解析及有记录的用时。使用题库冻结快照、范式的不可变题型版本和原子历史快照；缺少原版本时只保留答案与结果，不配上新版本题目。问答仍按原规则只显示解析，不暴露私有判题参考字段。

- 已开始学习的 Topic、已阅读指导、范式模块完成情况与熟练度、已训练的原子记忆点，以及题库训练记录。
- 全部已排程的范式复习、原子记忆点和题库卡片，包含已到期、尚未到期及暂停等受阻项。可筛选当前已到期、未来、受阻的任务。只读页面不为尚未学习的内容推算虚构的复习日期。
- 每个原子卡片变式的预计最早到期时间及对应记忆点日期。同点不同变式共用调度，初学未完成的点标明状态；尚未安排的卡片显示“尚未安排”。打包卡片只有在所有相关记忆点均已掌握并到期后才可能推送，其最早时间取这些点的最晚到期时间；实际卡片由现有算法选择，不会把每个变式都当成独立复习任务。

时间来自已有 FSRS/初学六小时排程，原子点的可再次出现时间包含同组块三分钟交错间隔。页面日期按当前管理员设置的时区显示。暂停、前置知识、账号停用、权限收回、其他正在进行的复习、停止推送和旧内容版本均保留排程日期并显示原因；日期并非保证实际推送的时间，后续作答可能调整它。

公开只读接口：`GET /api/admin/students`（`limit` 1–100、`offset`、姓名字面搜索 `q`）、`GET /api/admin/students/{learner_id}`（`days` 1–366、`timezone`），以及详情下的 `/questions`、`/history`。题目页以 `kind=topic|training|notebook`、`container`、`group`、`state` 和 `q` 筛选；历史以 `kind=topic|training`、`container`、`question` / `point`、`version` 筛选。题目每页最多 100 项，正文历史每页最多 30 项。

均执行服务端管理员身份检查，未知或非学员目标返回 404；普通身份 403、匿名 401。测试材料过滤同样覆盖目录、计数、图表、错题本和正文历史；不能通过新增接口绕过。学员答案只在授权管理员按需展开的历史接口中返回，汇总不携带正文或答案，不返回凭据、判题内部字段或完整状态。

统计口径：只计已结算的系统判题及自主评分；判题故障、废弃结果、重试、草稿、仅打开题目或停止推送动作均不计作答。综合复习复用写回的题库作答或原子历史，同一次作答只计一次。自主评分单列，不混入系统正确率；原子变式按同一记忆点归并，范式按模块归并，反复出错区最多列 20 项。作答用时只累计实际保存的值，并显示覆盖数量，不能解释为完整学习时长。缺少正确率数据为“—”，缺少日期不补造。

读取在 SQLite 一致快照及 `query_only` 连接中完成。不会创建学员学习服务、触发状态初始化、版本迁移或复习重排，也不会保存管理员浏览进度。旧版及已下线内容的历史信息仍保留查看。

学习页与报表目录统一使用 `course_hierarchy.project_hierarchy()`：课程 ID 对应的隐式根节点不显示，真实子章节提升，直属 Topic 保留，按原目录顺序呈现。

验证：`tests/test_admin_students.py`、`tests/test_student_reports.py`；`scripts/student_reports_fixture.py` 和 `scripts/student_reports_acceptance.mjs` 使用独立合成数据完成桌面、手机、分页、键盘、图表、历史和只读指纹验收。
