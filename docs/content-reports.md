# 内容块答疑与质量反馈

- 学员和管理员在学习、复习、题库题目及解析中使用同一组入口。红色“内容质量不佳”在蓝色“请求答疑”上方，两行文字间隔为两倍行高；两者均可填写说明或留空提交。
- 共用组件为 `web/content-report.js` 的 `helpableContent`；需支持选中文字纠错时用 `reportableContent`。组件绑定内容块 ID 和不可变内容版本，不通过界面文字猜测位置。原子训练暂停和判题中的学习按钮锁定不影响这两个入口。
- 两类提交共用 `/api/help-requests`，`kind` 为 `help` 或 `quality`。旧请求默认 `help`，旧记录的重试仍保持幂等。共同使用每个身份每分钟三次的限制，重试不重复保存。
- Topic 使用 `topic_id`、可选 `question_id`；支持题目、解析、指导章节和记忆组块。独立题库另携带 `bank_id`、`group_id`，`topic_id` 必须是服务器对应的 `training.<bank_id>` 权限 ID。
- 后端核验学员资格、内容权限、所属学科、内容版本及题目位置，再从服务器内容取得标题和正文快照。提交不修改学习进度或复习排程。
- 管理员原“答疑请求”页同时显示两类记录，显示类型、课程/题库、Topic/题组、内容块 ID、标题和正文快照；题库链接带对应题目 ID。记录、总数和分页仍仅涵盖当前管理员负责的学员，归属配置不变。
