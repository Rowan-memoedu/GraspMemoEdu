# 目标隐性练习与动态解锁

整篇目标题先进入题库，再反推它需要的原子记忆点并设计课程。课程图谱引用题库中的题组；题面、作答记录与题组身份只有一份。协议 3 的课程图谱可包含同学科的题组成员，题组和 Topic 继续使用同一套前置边与跨图环路检查。

图谱页面从记忆点引用派生对应 Topic 到题组的前置关系，标记为记忆点条件。这些关系参与统一环路检查，但不额外要求相关 Topic 的所有补充内容都已完成。管理员预览中的解锁读取当前登录会话的临时学习状态。

## 同一套记忆点与评分

题库题目的 `point_ids` 可引用已有原子记忆点，格式为 `topic_id/point_id`。一个关联是单点卡，多个关联是打包卡，不增加目标专属卡片类型。引用在加载时校验，不能指向未知点或其他学科；学习者必须拥有各点所属 Topic 的访问权限。

`assessment: {version: 1, item_points: {control_id: [point_reference]}}` 与 Topic Flashcard 使用同一合同。一个空可考查多个点，一个点可由多个空共同检验。评分通过共享的 `AtomicLearningService._grade` 更新原有 FSRS 状态，一次作答每点至多更新一次。普通打包复习、综合复习卷与目标题共用这一逻辑。

没有被实际考查的词义或篇章理解点只列入解锁前置，不放入题目的评分关联。题库不为关联题创建 `training_memory`，也不为整篇文章增加第二份 FSRS 状态。已有不关联原子点的普通题库题目保留原行为。

## 内容属性与触发条件

题组可声明：

```json
{
  "unlock_policy": {
    "point_ids": ["topic-a/point-1", "topic-b/point-2"],
    "min_successful_reviews": 1,
    "min_stability_days": 7,
    "min_retrievability": 0.9
  }
}
```

这些阈值是本轮选定的产品规则。所有前置点必须学会、未暂停、至少有一次达到首次复习间隔的成功复习、最近复习成功、稳定性至少 7 天、当前保留度至少 0.90。成功间隔复习使用既有学习记录；当前保留度由官方 py-fsrs 计算。

解锁没有永久完成标记。学习页、题库页、打开和提交接口重新读取同一份学习状态；遗忘、答错、暂停、权限变化或正文版本变化都可以重新锁定。已提交作答的历史保留。正式评分发生前还核对各点的版本与状态指纹，旧作答不能覆盖后来发生的学习。

第一次完成已解锁目标题时，关联点不必到期，仍通过原有逐点评分进入 FSRS。之后题库中的未到期重做记录为练习，不通过连续提前作答反复增加稳定性。普通关联打包题只有全部被考查点到期才进入综合复习；到期题和目标的区别在推送条件。

目标完成状态与当前解锁状态相互独立：已完成的题组仍可能重新锁定，界面保留历史并显示当前条件。解锁前置集合可以大于实际评分集合。

## 课程生产

`scripts/produce_goal_course.py` 复用现有 Codex Exec 隔离客户端与执行凭据。输入是冻结的目标原文、空位标识和带来源的教学资料片段。

选材先用 `scripts/retrieve_goal_materials.py` 检索目标词汇及教学目标涉及的完整词条，保留释义、例句、翻译和对照说明。检索结果只是候选池，不能把命中数当作课程覆盖或质量证据。设计需明确各 Topic 实际采用的原材料、用途与原文引用；设计稿同时显示可核对的原文例句和来源链接。Topic 应可独立复用，记忆点保持原子性，不把几个需要不同证据的事实合成一点。

1. 提取逐空、词义与篇章目标，先确定完整教学范围，再组织为原子训练与范式训练 Topic。
2. 独立审核课程设计与原文证据，每个目标点保留准确引用。
3. 分 Topic 生成指导、记忆组块、单点卡、目标之外的打包卡或范式例题与练习。
4. 新执行仅看学员题面独立作答；另一执行结合来源、答案与盲答检查教学与评分。
5. 通过后机械输出既有结构化原子格式和 Topic v2 作者稿，沿用原转换器。

失败只重跑相应单元；通过单元保留。修改候选正文不能作为工作流通过的证据。源数据、执行记录和课程正文存放在产物目录，源码仓库只保留通用流程及隔离测试。

已审定的记忆点文字由设计阶段负责，正文生成须逐字保留；扩展讲解进入 Introduction。独立审查同时核对原材料是否真正用于教学，只有引用并不算完成选材。工作流发生明确修订时，可用 `--fresh-unit-attempts` 保留旧尝试并新建尝试；未知结果仍不覆盖或冒充通过。

引用文字不精确时，单独调用证据修复阶段，只允许更换引用元数据，再接受独立审查。设计审查使用完整冻结来源，避免来源窗口遗漏造成错误否决。已知失败的设计可用 `--revise-plan-attempt` 从保留的候选与原始资料继续修订；未知执行结果不会自动重复提交。

`scripts/prepare_goal_course.py --audit-goal` 保持原题题面不变，分别完成盲答、答案变体及计分关联提案、来源审查。原有答案不能丢弃；合理的其他答案不能误给它未检验的特定构形或概念计分。缺少可靠逐点证据的空仍计入整题结果，但不凭空更新记忆点。解锁所需知识与实际计分知识分别保留。

默认命令机械编译已通过的整门课程，复用结构化原子导入、Topic v2 作者导入和题库编译器，同时导出《课程讲义》和《练习与解析》。课程和题库分别保留原有身份，图谱仅引用二者。编译包包含测试材料标记。

测试课程与目标题库在激活前均纳入 `test-materials.json`，不改变正式账号学习记录。
