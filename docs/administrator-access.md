# 管理员内容访问

管理员是 `access_principals.is_admin=1` 的邀请码账号。该字段只由服务器 CLI 创建，不提供网页提权或账号管理接口。登录身份持久保存，学习行为不持久保存。

管理员动态拥有全部已注册 Topic 和功能权限，跳过 Topic 前置条件。进入内容后仍使用普通学习者的学习、暂停、作答与反馈流程。原子卡复习页按内容目录列出全部变体和综合卡，无须先学或到期；单卡入口在一次作答反馈后结束，不继续推送。

## 统一存储边界

API 的学习服务工厂按服务端身份选择存储。普通账号沿用正式 SQLite；管理员每个登录会话使用独立的内存 SQLite，复用同一套事务和状态机。日志输出与备份导出被禁用，正式数据库没有管理员学习状态、评分参数或复习任务。直接为管理员创建持久学习服务会被拒绝。

浏览器中的答案草稿、答题计时和待提交内容也只存内存。退出或替换身份时清空；页面重载会丢弃浏览器草稿，但同一登录的服务器临时流程可以继续。退出登录或服务重启后临时流程消失；在途判题完成后释放旧内存库。仅关闭浏览器不等于退出登录。

身份认证、邀请码和会话管理正常保存；用户主动修改的账号资料或发送的内容反馈仍按对应功能保存，不属于自动学习记录。

## 扩展契约

已支持的范式与原子训练模式新增课程、Topic、卡片时，权限与材料目录自动继承，无须添加管理员例外。新的训练模式应通过 `materials.MATERIAL_PROVIDERS` 注册材料，并使用共享学习服务工厂和存储接口；前端学习缓存使用 `createLearningCache`。不要直接写入正式数据库或 Web Storage。管理员学习存储拒绝持久化是最后一道保护。

## 发放

在服务器运行 `account-provision --batch <唯一批次> --learners 0 --tests 0 --admins 3 --output <私密文件>`。原始邀请码仅写入受限管理文件；命令回执、源码和公开资产不包含邀请码。同批次重复执行不会重复建号。角色随整站备份恢复。
