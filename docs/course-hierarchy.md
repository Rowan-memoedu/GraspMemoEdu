# 课程层级

课程目录 `catalog.json` 的 `units` 继续使用稳定的 `id`、`title`、`topic_ids`，新增可选的 `parent_id`。省略或填写 `null` 表示根节点。子节点通过父节点 ID 连接，深度不设固定上限，各分支可以在不同深度结束。父节点可同时包含直属 Topic 和子节点；纯分组节点使用空的 `topic_ids`。

课程与题库的选择页、顶部目录共用 `catalog-outline.js`，将已有 units / groups 显示为可折叠、可选择的大纲。选择任意目录后，以 URL 的 `root` 指定视图根：标题使用该层级名称，列表从其直属内容和下一层开始，不再显示该母节点或更高祖先。课程任务页使用 `courses/<course-id>`，题库任务页使用 `banks/<bank-id>`，没有 `root` 时展示完整课程或题库。两者共用 `catalog-workspace.js`，可通过百分比右侧的“重新选择主题”回到各自目录。选课时的目录偏好按账号、学科和课程保存在本浏览器；内容链接、完成返回和切换 tab 保留 `root`。

API 的 `root_id` 仅为视图范围，统一经 `course_hierarchy.select_subtree()` 投影，不创建课程副本、不迁移 Topic、题组或 FSRS 记录。dashboard 的进度、任务、历史与分页游标均绑定此范围；题库同样只显示所选分支。权限、测试材料及前置依赖仍按完整目录判定，不能通过选择下级目录绕过。图谱保留所选范围及其必要的外部前置节点，过滤其他无关分支。学习与题库正文都点击百分比打开图谱；课程选择页继续提供学习进度和知识图谱入口。

```json
"units": [
  {"id": "a", "title": "A", "topic_ids": []},
  {"id": "b", "title": "B", "parent_id": "a", "topic_ids": []},
  {"id": "c", "title": "C", "parent_id": "b", "topic_ids": ["topic-1"]},
  {"id": "d", "title": "D", "parent_id": "c", "topic_ids": ["topic-2"]}
]
```

每个课程 Topic 必须且只能归属一个节点。节点 ID 在同一课程中唯一，父节点必须存在，不允许环或自引用。节点顺序沿用目录顺序。目录解析和待学习投影使用迭代，避免层级深度受到 Python 递归上限影响。旧的平面 `units` 保留真实章节分组；未配置章节的课程直接显示 Topic，不为展示效果新增一层。与课程 ID 相同的根节点是课程存储容器，不在课程内部重复显示；其真实子章节直接成为显示的第一层，直属 Topic 保留原卡片入口。

`install-topic --unit <节点ID>` 可将新增 Topic 放到任意节点，不改动已有归属。分层描述位于私有课程目录中，不放入公共静态网站。现有备份和恢复保留父节点及个人开关。

课程任务页通过统一功能 `course_hierarchy` 开放该视图，要求高阶学习者资格；管理员沿用全功能权限。默认开启，设置页可关闭，个人偏好随账号跨设备保存。明确限制功能的账号仍遵循其功能限制；普通账号及游客保持平面列表，不显示开关。降级会立即失去该视图，重新升级保留原来的个人偏好。

复习任务独立放在前列，仅 Lesson 归组。组内保留所有未完成 Topic，包括暂停及前置受阻项，沿用原有卡片、状态和入口。没有可访问待学习后代的节点不显示，已完成 Topic 的复习任务不会使空分支重新显示。层级只表达归属，学习前置条件继续使用原有 `prerequisites`，Topic 内部显示和流程保持原样。

复习图标复用现有四条递增熟练度条，仅点亮第一条；它是任务类型标记，不替代该记忆点实际的熟练度数据。已完成复习记录也使用同一图标。

视觉参考：[Math Academy 五年级课程](https://mathacademy.com/courses/5th-grade-math) 的课程分组。真实课程的分层由作者在目录中配置，本次只提供通用结构，不新增教学内容或猜测已有课程的章节划分。
