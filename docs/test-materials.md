# 测试材料保留与管理员访问

测试材料不删除，通过独立的可见性标记限制为仅管理员可见。已有内容、版本、附件和学习记录保留。普通账号、高阶学习者、`purpose=test` 的测试账号以及游客都没有测试材料访问权；只有服务端确认的 `is_admin=1` 账号可访问，管理员学习仍使用内存存储。

## 唯一配置源

服务器私密数据目录中的 `test-materials.json`：

```json
{
  "schema": 1,
  "courses": ["example-test-course"],
  "topics": ["example-test-topic"],
  "banks": ["example-test-bank"],
  "guides": ["english"]
}
```

示例 ID 只说明格式，不是正式网站内容。课程标记覆盖其下当前及以后新增的所有 Topic 和卡片；Topic 标记覆盖其正文、练习、原子卡与复习；题库标记覆盖全部题组、题目、变式和组卷来源；指南标记覆盖该学科指南及引用附件。标记可以先于内容安装存在，确保测试材料导入后立即受限。它不修改内容哈希、FSRS 或账号原授权，也不根据标题中的“测试”等字样猜测范围。

配置缺省为空，原有正式内容行为不变。通过 SSH 在服务器维护，部署前校验并重载后端生效，不提供网页修改接口。配置损坏时拒绝启动，不能当作空配置开放内容。配置随整站备份和恢复保存。撤销标记会按账号原授权重新开放，应按一次明确的材料发布处理。

## 统一边界

- 目录、学科课程数量、学习任务、课程进度、知识图谱和权限列表不展示普通身份不可见的测试内容。
- 直接 Topic、题库、历史答案、素材、复习与组卷接口仍经后端权限校验，不能靠收藏旧网址或手工请求绕过。
- 已保存的答疑正文、回复、未读数和分页同样遵守来源的测试标记；记录仍保留供管理员查看。
- 指南正文与图片、下载附件一起限制；数学的旧指南附件地址及指向同一指南文件的学科别名同样受控。
- 试卷开始及结果应用时重新核验来源权限；材料改为测试后，旧普通用户试卷不能继续读取或改写排期。
- 不自动重新导入已下线的材料。恢复时使用原文件、稳定 ID 和版本，并先配置测试标记；不复制成另一套正式内容。正式课程不应依赖测试 Topic。

`tests/test_test_materials.py` 核验管理员、普通/高阶/测试账号、游客、直接链接、图谱、附件和备份恢复。页面仍复用既有学科、题库及管理员材料入口。
