# 语境学习与题内评分

Topic 可以附带阅读材料和题目音频。功能由内容字段开启，沿用现有账号、课程权限、测试材料、Flashcard、判题与 FSRS，不按学科分派业务。

## 同题中的不同记忆点

Flashcard 的 `point_ids` 仍是唯一的点关联。可选字段 `assessment: {version: 1, item_points: {小题ID: [点ID]}}` 将确定性小题关联到这张卡已有的点。填空、判断、配对、选择和复合题使用各自的稳定控件 ID；单个文本或选择题使用 `answer`。

有小题映射的点按小题判定，覆盖整题结果；未映射的点仍按整题判定。同一点映射多个小题时，需要全部正确。同次作答每个点最多更新一次，重复提交沿用既有幂等规则。限时复习的未答小题判错，已作答的小题保留自己的结果。语义判题和自主评分继续使用整题结果，不能声称做出了逐小题语义判定。

`assessment_result` 只在反馈中提供逐点结果、依据与小题 ID；作答前不提供答案。历史记录保留本次判定，综合复习复用同一原子评分入口。没有这个可选字段的旧题继续使用原有行为。

## 阅读与记忆

`reading_materials` 包含材料 ID、标题、纯文本段落和可选词注。词注以 Unicode 字符位置绑定原文，可携带释义、助记、词义关系和已有记忆点。词源信息须注明来源；词义关系不能当作词根关系。

选词请求携带正文版本、段落 ID、精确引用、前后各最多 50 字与字符位置。服务器验证原文后才能保存笔记、疑惑和上下文。已有词注优先于通用词典；通用查词使用固定版本的离线 Open English WordNet，保留多个义项，不自动认定当前语境的词义。

加入记忆时，已有点进入原初学流程的待学集合。它不会立即被标成掌握，也不会生成第二份 FSRS 卡；完成初学后才沿原规则产生复习日期。当前作答、指导顺序和已有间隔限制保持有效。已经掌握的点仅保存新的语境，不重置其排程。

没有现成点的选择保存为候选，尚不进入复习。本人可下载私密记录，由[本地生产流程](context-production.md)分析、选择义项、形成指导与种子题、审核后导入。旧版本的阅读笔记保留原引用和上下文，并明确标记为旧版本，不能用旧字符位置指向新正文。

阅读记录保存在原学习数据库的 `reading_contexts`，按学习者隔离；管理员浏览使用既有临时预览存储。网站备份保留这些记录。词典属于可重建的运行资源，单独保留原始来源哈希、准备命令和许可证。

## 听力与口语

题目可携带 `audio: {version: 1, asset: "audio/<sha256>.mp3", mime_type: "audio/mpeg", mode: "listen", transcript: "..."}`。模式还包括 `dictation`、`read_aloud`、`retell`；WAV 使用对应扩展名和 MIME。音频路径相对于 Topic 文件，运行时核对路径、字节哈希、格式和 10 MiB 上限。音频随内容包和网站备份保存。稿件仅在反馈时提供。

朗读与复述支持浏览器录音，使用单声道 16 kHz PCM WAV；每次最多 120 秒，服务端同时核对真实音频时长与大小。提交转写需要登录、有作答权限且有题目访问权限。转写共用现有每日服务调用额度，另有每人每分钟和全局并发限制。转写后可编辑文字，再交由原判题流程判断内容；转写本身不评分、不推进学习，也不代表发音评分。

服务器通过 `GRASPMEMOEDU_ASR_API_KEY` 配置 Fun-ASR，密钥只进入服务器私密环境文件。转写不可用时可直接输入答案。浏览器在离开页面、切题或销毁控件时停止录音。nginx 仅 `/api/training-audio/transcribe` 放宽至 6 MiB；普通请求继续使用原限制。

## 词典准备与复用

运行依赖固定为 Wn 1.1.1 和普通版 OEWN 2025。在本地运行 `python scripts/prepare_context_dictionary.py --output <D盘目录> --download`，或指定经过哈希验证的本地来源及许可证完成离线重建。运行时需要 `wn.db`、`dictionary-manifest.json` 和 `licenses/`，放到服务数据目录的 `context-dictionary/`。

适配器只读数据库；缺少词库、未找到词条或不兼容时阅读与已有词注仍可用。OEWN 的 CC BY 4.0 与底层 Princeton WordNet 许可、出处和字段裁剪说明随查词结果提供。它提供英文释义及义项关系，不提供未经来源支持的词源，也不代替语境义项审核。
