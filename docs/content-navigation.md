本次参考 `D:/Artifacts/HyperskillFeatureStudy/step-14404` 的 SPEC、数据示例、验收清单及公开生产 bundle 摘录；来源为 <https://hyperskill.org/learn/step/14404>。参考范围是组件布局、上下移动、选区上下文与实时替换预览、顶部展开目录。实现继续使用本项目原生 JS、MathJax、鉴权与接口，配对逻辑遵循用户定义的选项池、干扰项、固定侧和一对一箭头，不采用原站固定左列/只排序右列的数据协议。

## 文字纠错

在题干、指导或已显示的解析中选择文字，按 Ctrl/Command+Enter，或点击“报告选中文字”。起止位置必须属于同一个正文块；输入框中的 Ctrl+Enter 仍是提交答案。

表单显示原文、替换后预览、建议文字和可选备注。建议留空明确表示删除所选文字。取消不写入；失败保留窗口和草稿；只有收到 `status: saved` 才确认保存。保存建议不会改动原文、答案或学习进度。

复用 `POST /api/feedback`，增加可选 `correction`：

```json
{"content_block_id":"question:example-1","content_version":"发布版本","quote":{"exact":"被选文字","prefix":"最多50字符前文","suffix":"最多50字符后文","start":0,"end":4},"operation":"replace","replacement":"建议文字","comment":""}
```

偏移按 Unicode 码点计数，解决重复词定位；题干填空控件会还原为作者标记后计算位置。服务端检查 Topic 权限、已访问题目、版本和精确引文；版本已变返回 409。旧普通反馈接口兼容，结构字段存入与 `feedback` 同事务写入的 `feedback_corrections` 表。反馈仅在服务端留存，没有外发或自动改稿流程。

## 学科/课程目录

顶部“目录”展开白底面板，先浏览学科，再按权限选择课程或题库。面板即时使用当前浏览学科的主题色：顶部色线、学科选中边框、课程和题库选中态及浅色填充统一取自 `subjectPalette`。浏览和已选课程分开；空学科与受限课程分别提示。同名课程按稳定 ID 区分。课程保存复用 `POST /api/catalog/select?subject_id=...`，确认返回课程 ID 后进入该学科学习页；题库使用同学科的既有题库入口。

打开、关闭、切换学科与身份变化均通过请求序号拦截旧响应；保存期间防重复点击。支持再次点击入口、点击面板外部和 Escape 关闭，键盘关闭后焦点回到入口。切换只改变课程偏好和路由，不改原题进度；未提交答案留在既有浏览器草稿里。

顶部“题库”在本次访问中记住每个学科最后打开的题库、题组和题目，切到学习、复习、指南等页面后再点“题库”，回到对应位置并恢复正文与题目目录的滚动位置。题目切换使用的 `replaceState` 同样纳入位置记录；返回按钮或目录仍可主动进入上层。身份或权限切换清空位置记录，不写入持久缓存。单卡复习属于复习标签，不覆盖题库位置。

测试命令与共享架构见 [共用平台](shared-platform.md)。故障注入只用于隔离浏览器验收，不进入正式应用。
