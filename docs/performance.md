# 页面加载与内容缓存

各学科共用同一层缓存，不改变权限、判题、学习记录或 FSRS。

目录与导航的最近响应保存在当前页面内存中：身份 10 秒，目录、题库分组和指南 15 秒，学习首页 5 秒。同一页面内的并发读取合并；每个调用者取得独立副本。作答、选课、设置等写入在开始和结束时使缓存失效；切换账号、收到其他标签页的学习更新、窗口重新获得焦点或恢复网络也会失效。学习状态、判题结果和提交操作不复用这类短期响应。

正文、已允许查看的解析和公式样式另外保存在 IndexedDB。请求仍经原接口确认身份、权限和当前状态。客户端通过 `content_revision` 声明已有正文；服务器从本次授权后的响应计算内容版本，匹配时只传当前位置、进度等数据及正文引用。进入下一步或正文更新时，复用其中未变的块，只补充新增正文；服务器只保留最多 128 个版本、8192 个块指纹的索引，索引失效则返回完整正文。服务器不提供按哈希绕过鉴权下载内容的入口。旧客户端不带此参数时仍收到原格式，旧服务端忽略该参数时新客户端也能正常工作。

持久缓存按 API 来源、学习者、身份资格及 Topic/功能权限隔离，只保存展示文本，不保存作答、提交结果或进度对象。管理员内容仅在内存中复用。退出或切换身份会清理缓存；容量上限约 32 MiB、80 项，单项不超过 16 MiB，最多复用 7 天，后续写入时清理过期项。存储被禁止、达到配额或读取超时时直接退回联网。读取遇到缓存缺失时最多重新读取一次完整正文；学习操作仍逐次发送到服务器，仅压缩它们的响应，不缓存或自动重放写入。

页面切换期间保留原有画面并禁用旧操作，新页面就绪后替换。进入 Topic 时复用路由已经取得的状态，避免再读取同一正文。页面刷新后的进度仍以服务器为准；本机制不提供离线作答。

`tests/test_response_content.py` 检查兼容性、身份验证、正文更新及传输缩减；`tests/response_cache.test.mjs` 检查请求合并、失效竞争、账号隔离、存储故障和管理员边界。`scripts/performance_fixture.py` 与 `performance_acceptance.mjs` 在独立合成数据上对比页面耗时、请求数、正文大小、刷新恢复和移动端布局，不能用于正式账号的学习操作。
