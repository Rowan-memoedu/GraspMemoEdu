# 复习组卷类型

本文件是组卷配置的数据源。每个二级标题是一种卷型。可直接修改“名称”和“限时（分钟）”；名称显示为复习目录的根节点，其下显示卷一、卷二等可开始的试卷。限时是整张卷的总时间，必须为 1–1440 的整数分钟；刷新和切换后台继续计时。默认到时自动交卷，未答部分计错；高阶学习者可在系统设置选择超时仅标记、不中断。

ID 和学科使用稳定英文标识，题量为非负整数，至少一种题型大于零。支持单选、多选、填空、问答、判断、配对。修改后通过配置校验并部署生效，已开始的试卷保留原名称、限时和超时策略快照。以下名称和时长为可修改的初始默认值。
